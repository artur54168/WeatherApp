# React + Vite + Docker

Aplikacja do Prognozy pogody dla wyszukiwanego miasta/miast.

Aplikacja zintegrowana z API , wyświetla aktualne dane dla podanych miejscowości.

# Uruchomienie Aplikacji
Do uruchomienia potrzebna jest tylko aktualna i skonfigurowana aplikacja Docker.

Aby uruchomić aplikację pobieramy repozytorium następnie wchodzimy w lokazlizację gdzie pobraliśmy repo i uruchamiamy za pomocą komendy docker-compose up -d.
Aplikacja uruchomi się pod linkiem: http://localhost:3000/
